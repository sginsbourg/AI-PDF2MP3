# PDF2MP3: Professional PDF-to-Audiobook Intelligence Suite

PDF2MP3 is a high-fidelity, autonomous pipeline designed to transform static PDF documents into immersive, pleasant audiobook experiences. Unlike basic TTS tools, PDF2MP3 utilizes a **7-Step Procedural Architecture** with smart-pause injection and subprocess isolation to ensure rock-solid stability and a professional narrative flow.

## 📋 System Overview
The engine extracts, structures, and synthesizes text into high-quality MP3 assets. It is optimized for long-form content like research papers, books, and technical manuscripts where narrative timing and system resilience are critical.

## 🏗 The 7-Step High-Fidelity Pipeline

The system operates on a deterministic, procedural cycle:

1.  **Ingestion**: Capture PDF path via CLI or GUI.
2.  **Extraction**: Robust text extraction with layout awareness.
3.  **Structuring**: Transformation of raw text into a **Structured JSON Schema**, classifying segments into headings and paragraphs.
4.  **Isolated Synthesis**: Synthesis of each segment using **Subprocess Isolation**. Every paragraph is recorded in a fresh process to prevent Windows SAPI5 memory leaks or COM-engine hangs.
5.  **Smart Merging**: Integration of segments using FFmpeg with context-aware pauses:
    - **Breath Pauses**: Short breaks after paragraphs.
    - **Transition Pauses**: Extended breaks after headings and section changes.
6.  **Metadata Persistence**: Saving the structured JSON to the `json/` directory for audit and future intelligence tasks.
7.  **Finalization**: Deployment of the optimized MP3 to the `mp3/` folder.

## 🔍 Troubleshooting
- **Audio Hangs**: Fixed via Subprocess Isolation. If synthesis stops, check your default Windows voice settings.
- **FFmpeg Errors**: Ensure `ffmpeg -version` is executable in your terminal.
- **Voice Selection**: The engine prioritizes "Microsoft David" or any English Male voice available on your system for a professional "narrator" feel.
